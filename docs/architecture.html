Two-Dimensional Grid Engine

Combine column definitions, row data, and templates to produce rows containing their cell element trees.

Responsibility

The two-dimensional engine combines a column schema with data rows and a named template library. For each data row, it resolves a row template and creates a cell for each column, returning an array of row element trees.

Input → transformation → output

Column definitions+Data rows+Named templates→Row trees with cell children
twoDimensional(columns, rows, spec)
  → [
      { tagName: "tr",
        children: [
          { tagName: "td", textContent: "Keyboard" },
          { tagName: "td", textContent: "Accessories" }
        ]
      }
    ]

The column schema selects cell template keys and maps each column to the matching value in the current data row. The primitive engine resolves the row and cell templates.

What it does not own

The engine returns row trees; it does not create the outer <table>, header structure, or surrounding container. Those belong in the base structure and are populated by the coordinating sample or orchestrator.
